# Créditos tipográficos

**Sekaiwo Regular**, de tkzgraphic, é a única fonte decorativa usada na identidade visual do site: wordmark “Kazuji”, destaque “no seu ritmo.”, selo “K” e letreiro “ANDROID”.

O autor autoriza uso pessoal e comercial no README que acompanha o pacote original, preservado neste diretório como SEKAIWO-READ-ME.txt. A página da fonte informa suporte a português:
https://www.1001fonts.com/sekaiwo-font.html

O repositório contém somente vetores SVG dos dizeres usados no site, não os arquivos TTF/OTF. A autorização gratuita para uso comercial não equivale a uma licença aberta como SIL OFL.
